# 7xLauncher rebranding notes

- Display name: 7xLauncher
- Maintainer branding: 7xPojav_
- Theme accent: aqua
- Launcher icon: custom white 7X on black
- Android application ID: `com.x7pojav.launcher` so it can be installed alongside the original app (Android treats different application IDs as separate apps).
- Internal Kotlin namespace/package names are intentionally preserved to reduce risk of breaking JNI/native integrations.
- This is a community rebrand/fork of Hyper Launcher 3. Original upstream attribution, third-party notices, and LGPLv3 license must be retained. Do not present the inherited code as independently authored.
